# ☕ Coffee Website

A modern and responsive coffee shop website created using **HTML, CSS, and JavaScript**.  
This project provides a visually appealing interface for exploring a coffee shop's menu and interacting with different website sections.

## 🌐 Project Overview

The Coffee Website is designed to provide a simple and attractive online experience for coffee lovers. It includes a clean layout, menu section, interactive elements, and a responsive design suitable for different screen sizes.

## ✨ Features

- ☕ Attractive coffee shop homepage
- 📋 Interactive menu section
- 🛒 Order button functionality
- 📱 Responsive design
- 🎨 Modern and clean UI
- ⚡ JavaScript-based interactions
- 🌐 Easy navigation between sections

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
